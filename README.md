# 跨学科论文评审与双语意见

一个可配置研究方向的 Agent Skill，用于独立阅读论文，生成阅读笔记和有证据的中英文审稿草稿。通用流程不绑定任何学科；解释和检查项取决于用户背景、论文内容与研究设计。

> 跨学科适配不等于已经在所有学科上验证。它是供科研人员核查和迭代的助手，专业判断仍需对应领域证据。

## 能做什么

- 从 PDF 读取到阅读笔记、证据表、主要/次要意见，完整独立运行。
- 根据实验、统计、计算、理论、定性或综述等研究设计选择适用检查。
- 默认生成对应的中英文审稿意见，统一术语、证据位置、编号和严重程度。
- 区分已成立问题、缺材料待核实项及可选扩展；不为凑数生成批评。
- 适用于投稿前自查、模拟评审和受托审稿；不会自动向期刊提交。

## 安装与环境

将整个仓库放入支持 Agent Skills 的助手所配置的技能目录，保留 `SKILL.md` 和 `references/` 的相对位置。不同宿主的技能目录和加载方式不同，应使用该宿主提供的技能安装功能或指定目录。

在已选定的技能父目录中可运行：

```sh
git clone https://github.com/Moshern/review-comment-sci-PDF.git review-comment-sci-pdf
```

技能标识使用小写 `review-comment-sci-pdf`，GitHub 仓库名保留原有 `review-comment-sci-PDF`。从旧版迁移时，修改调用名称，避免新旧副本同时加载。仓库中可选的 `agents/openai.yaml` 提供界面信息，不是通用执行依赖。

这是指令型技能，没有后台服务，也不需要专用 API 密钥。最低需要能够读取文件/附件的智能体和可用的 PDF 阅读能力；输出保存需要文件写入能力。按环境选择一种读取路径：

| 能力 | 用途 | 缺失时 |
|---|---|---|
| 原生 PDF 阅读或本地解析器（如 Poppler/PyMuPDF） | 读取正文并定位页码 | 请求可读取版本，不声称已读 |
| 页面视觉读取 | 核对图表、公式和排版 | 标记未核验图像，只解释图注/正文 |
| OCR（扫描件需要） | 识别扫描页面 | 请求文字版或说明覆盖限制 |
| 网络检索（可选） | 核验外部背景、术语和相关工作 | 本地阅读仍可继续，标记外部未核验 |

安装 Poppler 后可在终端用 `pdfinfo -v` 和 `pdftotext -v` 检查其是否可用。具体读取与失败处理见 [PDF 阅读流程](references/pdf-reading.md)。不承诺解决所有编码、加密或扫描质量问题。

**独立性**：不需要安装论文阅读 skill、PDF skill 或其他技能包。读取、笔记、术语配置和评审步骤均在本仓库内提供。

## 最短使用方式

支持 `$技能名` 的助手可输入：

```text
请使用 $review-comment-sci-pdf 处理 ./paper.pdf。
我的研究方向是教育学，主要做访谈与定性分析。
请独立阅读论文，生成阅读笔记和有证据的中英文审稿草稿。
```

不支持该语法的宿主，可明确让助手读取本仓库的 `SKILL.md` 并执行。PDF 路径替换成真实文件；宿主需要能够访问它。

## 如何注入你的专业背景和术语

无需改 skill 正文。每次提问提供方向、已有知识和专业资料，助手会建立本次领域配置和术语表。只给方向也可以；没有方向时从论文暂定，遇到影响判断的歧义再询问。

```text
请使用 $review-comment-sci-pdf 处理 ./paper.pdf。
研究方向：材料科学，电池材料。
我的背景：熟悉实验表征，对论文使用的统计分析不熟悉。
重点问题：核心结论由哪些实验支持？适用范围是什么？
术语资料：请读取 ./my-glossary.md；原文定义优先，冲突请说明。
背景资料：请读取 ./method-notes.md，注明哪些内容来自这些资料。
输出语言：中文及英文。
目标期刊：暂不指定，按本文研究设计做通用评审。
本次不要联网；不确定的外部依据列为待核实。
```

你可以自建 `my-glossary.md`，每行包含“原文术语、首选译名、含义/适用语境、来源”。模板见 [领域配置](references/domain-profile.md)。这些用户文件不是仓库必备文件；没有时直接在对话里给出内容。

实际使用规则：

1. 原文定义用于解读论文，个人译名偏好用于表达；发生冲突会明确说明。
2. 外部资料与原文证据分别记录。未核验术语保留原文，不猜译名。
3. 跨学科论文可输入多个方向，但检查项依据论文实际方法选择。
4. 更换研究方向只需要换配置，不需要重新安装或编辑技能。
5. 用户资料和论文属于研究输入，默认不提交到本仓库。

## 输出

默认位置是 `outputs/<论文标识>/`，用户指定目录优先：

`AI阅读笔记.md`、`审稿意见_<论文标识>.md`、`Review_<论文标识>.md`；正式审稿按需另生成编辑专阅文件。

笔记含阅读覆盖和未核验项；证据位置使用 PDF 页码（从 1 开始）及原图表/公式编号。不会用固定文件名覆盖其他论文。审稿意见数量由证据决定，可以没有主要问题；关键证据缺失时暂不作最终建议。

回归场景用于人工或智能体自测；预期行为不是已经通过的运行结果，也不是专业准确率证明。不要将审稿中的保密论文作为公开示例上传。

## 适用边界

只有摘要、缺页或无法核验的图表时，只能生成范围明确的部分分析。未经检索不能断言创新性，未经实际重算不能声称复现。编辑意见和双语草稿都需要用户确认事实与专业判断。
