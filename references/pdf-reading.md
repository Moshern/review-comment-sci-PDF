# 独立 PDF 阅读流程

不依赖其他 skill，不要求特定产品的 Glob、Read、Bash 或 AskUserQuestion 工具名。选择当前环境实际可用的文件读取、终端、PDF 视觉和 OCR 能力。

## 1. 检查输入与能力

确认源文件、页数和加密/可读状态。若安装了 Poppler，可运行：

```sh
pdfinfo "paper.pdf"
```

PDF 元数据可能缺标题或 DOI，必须回查正文，不能把元数据工具视为完整书目信息源。真正需要密码时请求有权访问的解锁副本或密码；解析错误本身不能证明加密，也不能证明是误报。

## 2. 提取文字并检查覆盖

原生 PDF 阅读可用时直接使用并保留页码。否则可按当前工具条件选择：

```sh
pdftotext -layout "paper.pdf" "paper.txt"
pdftohtml -s "paper.pdf" "paper.html"
```

命令路径均为示例，执行时替换成实际文件，并按当前 shell 安全传参。把转换产物写到论文专属输出目录，保留原 PDF。

也可使用已安装的 PyMuPDF 等本地解析库。HTML 能产生文件不代表提取成功；文本方式与 HTML 方式均可能遗漏内容。出现乱码、空页、双栏乱序、公式丢失时对照原页，更换解析器或视觉读取；扫描页用可用的 OCR 后回看原图。没有所需能力时说明限制，不编造已读取内容。

逐页记录：PDF 页号、章节/图表、提取状态、是否视觉核验和未解决问题。抽查首页、跨栏段落、关键方法/结果页以及公式图表；逐页覆盖记录不能用少量抽查替代。

## 3. 核对图表、公式和数字

按页查看图表原图；无法查看时仅基于图注/正文解读并明确标记。表格需核对表头、列对齐和脚注；公式需核对上下标、正负号及希腊字母。OCR 结果尤其需要复核小数点和符号。

图像或流程图不必有坐标轴；定性、理论和综述文献不一定有统计量。不要补造不适用字段。

## 4. 建立证据记录

| 主张或数据 | 原文位置 | 直接证据 | 作者解释 | 限制/待核验 |
|---|---|---|---|---|

PDF 页码从 1 开始，并区别于印刷页码。图/表/公式使用原编号，无编号内容使用章节和 PDF 页码，不杜撰行号。

可按章节分批阅读长文，持续更新覆盖和证据记录。完整性只能针对实际提供的材料声明；缺失附录、不可读页或仅有摘要时缩小结论范围。

## 5. 外部资料与输出边界

外部检索用于背景、术语或必要的相关研究核验。优先原始论文、方法原典、官方指南等，记录标题、链接或 DOI 及支持何种判断。不要固定依赖某个付费数据库，也不把检索摘要视为已读全文。

不将未发表全文、个人资料或保密附件自动上传到外部服务。联网不可用时仍可完成有明确范围的本地阅读，不声称已经核验外部事实。
