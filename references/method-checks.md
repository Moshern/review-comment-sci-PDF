# 按研究设计选择审查项

条目是判断线索，不是所有论文必须满足的清单。先确认论文的核心主张、研究范式及证据类型，再选有关项目。缺一项不自动构成主要缺陷，严重程度由对结论的影响决定。

| 研究类型 | 可检查的关键关系 | 避免误用 |
|---|---|---|
| 实验/测量 | 材料和操作、对照、测量校准、重复、误差来源与主要结论的关系 | 不把某一学科的样本量或参数范围当通用阈值 |
| 观察/统计/因果研究 | 样本来源、偏差、混杂、缺失数据、估计目标、假设、不确定性、稳健性 | 相关不等于因果；显著性不等于效应的重要性 |
| 计算/数值研究 | 模型假设、离散/求解误差、条件设定、验证及适用范围 | 只在存在相应离散过程时检查网格/时间步等依赖性 |
| 机器学习/数据方法 | 数据来源与划分、泄漏、基线公平性、指标、重复性、必要的消融与资源报告 | 性能主张不同，验证要求不同；不把缺训练曲线自动判为主要问题 |
| 数学/形式理论 | 定义、定理前提、证明逻辑、反例、边界情况、与已有结果的关系 | 不要求本来不需要的实验、训练或统计检验 |
| 定性/人文/解释性研究 | 材料选择、语境、解释框架、论据到结论的路径、替代解读与透明度 | 按研究传统判断是否需要反思性、三角互证等，不套量化显著性标准 |
| 系统综述/证据综合 | 检索覆盖、纳排规则、筛选、质量/偏倚评估、合成方法、异质性 | 不把系统综述的完整流程强加给叙述性评论 |
| 混合方法/跨学科 | 各方法证据质量及整合方式，概念转换是否改变含义 | 一个分支的证据不能自动支持另一个分支的主张 |

## 保留原审稿经验的通用判断

### 应用相关性

将研究条件、材料或对象与声称的应用逐项比较。有来源的差异可以提示外推风险；只有在差异破坏核心应用主张时才构成主要问题。不要使用未经核验的“典型值”表直接判错；概念验证无需自动满足全部真实应用条件。

### 收敛与成本

论文声称精度、效率或优化优势时，检查与该主张有关的停止准则、结果稳定性和比较条件。成本比较说明硬件、规模、精度目标以及训练/推理或预处理/求解阶段。更慢但更准的方法可能存在合理权衡，不预设其没有价值。

### 预处理与鲁棒性归因

画清“原始数据 → 预处理 → 方法 → 输出”的路径，核查扰动位置、训练和测试条件、残余误差及对照公平性。去噪不会自动消除全部噪声，完整流程可以具有鲁棒性；只有把流程效果归于单个组件而证据不足时，要求组件对照或收窄表述。

### 近似、敏感性与边界

论文使用截断、近似、降维或简化假设时，检查误差依据和适用范围。更高阶或更复杂方法是可能的验证方式，不是必需的新工作；建议最小充分分析来支持原有主张。参数交互只在影响结论时提出。

### 创新性与相关工作

比较作者实际主张与已核验的相关工作，包括必要时的作者前作；关注假设、方法、证据或适用范围的差异。不固定论文名、作者、参考文献编号或期刊名单。未读取相关工作时只提出需澄清的比较问题。
